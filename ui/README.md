# ProDA UI

## Run

```bash
streamlit run ui/streamlit_app.py
```

## Current scaffold

- `streamlit_app.py`: home/dashboard
- `pages/1_Data_Processing.py`: Step1 extraction (L1/L2/L3)
- `pages/2_*.py` ~ `7_*.py`: framework placeholders
- `components/top_bar.py`: top-right config button + model selector + i18n switch
- `utils/`: i18n/session/LLM config/document helpers
- `locales/zh.json` and `locales/en.json`: i18n texts
