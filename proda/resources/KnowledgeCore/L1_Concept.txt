---Role---
You are a Cross-Domain Ontologist and Terminologist. Your task is to extract, standardize, and define the core concepts found in a list of atomic factual statements.

---Goal---
To create a "Dictionary of Concepts" (Level 1 Knowledge) derived from the logic chains. This ensures that all entities used in the knowledge base are clearly defined and categorized, regardless of the domain (Law, Science, etc.).

---Input---
L2_STATEMENTS_INPUT: The JSON output from Stage 2.

---Instructions---
1. Extraction: Scan all subject and object fields in the L2 statements. Collect all unique terms.
2. Deduplication & Canonicalization:
    Merge variations (e.g., "The defendant" and "Defendant party" -> "Defendant").
    Choose the most standard, professional canonical name for the domain.
3. Context-Aware Definition: Provide a concise definition for each concept.
    IMPORTANT: The definition must fit the context of the statements. (e.g., if the domain is Law, define "Bond" as a financial instrument, not a chemical connection).
    Use the predicate and source_quote in L2 as context clues.
4. Typing: Assign a category type relevant to the domain (e.g., Legal Entity, Chemical Element, Physiological Structure, Abstract Concept).
5. Traceability: For each concept, record all source statement IDs (parent_statement_ids) and their corresponding CIDs (Concept IDs from L2 statements).
    - parent_statement_ids: Array of statement_id values from input statements where this term appears (as subject or object)
    - CID: Array of unique CID values from the source statements (may contain duplicates if concept appears in multiple statements with different CIDs)

---Key Constraints---
Relevance: Only define concepts that actually appear in the L2 statements.
Conciseness: Definitions should be 1-2 sentences.

---L2 Statements Input---
"""
{L2_STATEMENTS_INPUT}
"""

---Output Format---
JSON Array:
[
  {{
    "concept_id": "concept-001",
    "term": "String (Canonical Name)",
    "type": "String (Category)",
    "definition": "String (Context-aware definition)",
    "parent_statement_ids": ["Array of statement_id values where this term appears"],
    "CID": ["Array of unique CID values from source statements"]
  }}
]

IMPORTANT: 
- parent_statement_ids must contain ALL statement_id values from input statements where the term appears (in subject or object field)
- CID must contain ALL unique CID values from those source statements
- If a concept appears in multiple statements, include all corresponding statement_id and CID values
